# Installing

`yay -S asusctl supergfxctl`


# Installed asusctl

changing profile

`asusctl profile -P Quiet`
`asusctl profile -P Balanced`
`asusctl profile -P Performance`

Keyboard Control commands
Set bright ntensity
`asusctl -k off`
`asusctl -k low`
`asusctl -k med`
`asusctl -k high`

Set color RGB keyboard
`asusctl aura static -c 00ff00`
