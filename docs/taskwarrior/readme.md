# Taskwarrior

run with `task`, if not .taskrc found, this will ask you to create one in ~/.taskrc.

# Basic functions

Adding task 

```
task add Install git \

due:
    eow: end of week
    eoy: end of year
    5d: five days

+linux
```

# Projects

```
task add Write the script of a video project:video
task add Record the audio project:video
task add Edit the footage project:video
```

`task`

# Exports

task export > task.json
